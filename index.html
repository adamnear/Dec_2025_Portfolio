  • Professional Layout Design: Developed a high-contrast print layout with a black canvas, disabling background rendering to allow the hydrological network to stand out as the primary focal point.

Outcomes: The resulting map effectively highlights the Amazon basin’s intricate structure, demonstrating advanced competency in vector data management and thematic cartography. This workflow can be adapted for any global region to support climatology, hydrology, or environmental planning studies.

Project Summary: Supervised Land Classification

Domain: Land Analysis / Forestry Skill: Remote Sensing / GIS

This project involved performing a complex Supervised Image Classification of Landsat 9 multispectral imagery covering the Annapolis Valley, Nova Scotia. Using Catalyst Focus and ArcGIS Pro, I transformed raw spectral data into a refined thematic map identifying six primary land cover information classes.

Key Technical Workflows:

  • Image Preparation & Pan-sharpening: Processed Level 1 Landsat 9 bundles, performing pan-sharpening and clipping to a specific area of interest (AOI) to enhance spatial resolution for feature identification.
  • Supervised Training & Signature Analysis: Manually digitized training areas to create distinct spectral classes. Evaluated signature quality using Bhattacharrya Distance for separability, scatter plots for spectral overlap, and histograms for class homogeneity.
  • Class Aggregation & Post-Processing: Aggregated various spectral classes (e.g., bare soil, rock, and quarry) into higher-level Information Classes (e.g., Barren). Applied a Sieve Filter to reduce "salt-and-pepper" noise while maintaining critical linear features like transportation networks.
  • Rigorous Accuracy Assessment: Conducted a non-biased accuracy assessment using 25+ independent random reference samples per class. Generated Confusion Matrices and Kappa Coefficients to statistically validate the classification reliability.

Outcomes: The final output was a 24” x 36” professional-grade map following NRCAN standards. The project demonstrated proficiency in the full remote sensing lifecycle—from raw sensor data ingestion and statistical validation to final cartographic production.

Project Summary: Solar Power Plant Suitability Analysis

Domain: Renewable Energy / Infrastructure Planning Skill: Raster Analysis / Modelling

This multi-stage project involved a comprehensive raster-based suitability study to identify optimal locations for a solar power plant in Nova Scotia. By transitioning from a Binary Coincidence (Pass/Fail) model to a Weighted Ranking technique, the analysis provided a nuanced gradient of land feasibility based on topography and infrastructure proximity.

Technical Workflow:

  • Surface Analysis & Terrain Modeling: Derived Slope and Aspect rasters from a Digital Elevation Model (DEM). A Hillshade was generated to provide 3D visual context for site morphology.
  • Binary Coincidence (Phase A): Developed a boolean logic model using the Con Tool and Map Algebra. Sites were filtered to meet strict thresholds: Slopes (6°–18°), South-facing Aspects (112.5°–247°), and proximity to transmission lines (less than 2000m).
  • Environmental Masking: Engineered a land-only study area by converting hydrographic vector data into a raster mask. Utilized IsNull and SetNull functions to ensure water bodies were excluded from geoprocessing calculations.
  • Multi-Criteria Weighted Overlay (Phase B): Transitioned to a ranking system where variables were reclassified into a 1–9 scale. These were integrated using the Weighted Overlay tool to allow for trade-offs between criteria.

Infrastructure & Weighting Logic:

A critical component of the model was the proximity to the electrical grid. Using Euclidean Distance, the transmission line influence was calculated and integrated into the final weighted model.

Project Summary: WindPRO Environmental & Yield Assessment

Technical & Assessment Contributions:

  • Acoustic Propagation Modeling: Implemented the ISO 9613-2:2024 noise model to calculate sound pressure levels for five BONUS 1.3 MW turbines, accounting for wind speeds from 4.0 m/s to 12.0 m/s.

  • Regulatory Threshold Analysis: Benchmarked results against ETSU-R-97 guidelines, utilizing a 90% exceedance value (L90) with a 5dB margin above ambient noise and a 35dB floor setting for compliance.
  • Spectral Data Integration: Processed octave band data (63 Hz to 8,000 Hz) to account for frequency-dependent air absorption at 10.0°C and 70% humidity.

  • Wake Loss & Energy Yield (PARK): Executed a production analysis using the N.O. Jensen (RISØ/EMD) Park 2 model to evaluate a 17.3 MW hybrid array. Calculated a total farm wake loss of 5.1%, achieving a Net AEP of 65,963.1 MWh/y.
